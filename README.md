# 2026-11-15｜Python 爬蟲課學生教材

本次教材包含：

- `lesson01_python_warmup`
- `lesson02_network_and_environment`

Lesson 01 的 15 題練習請開啟 `lessons/lesson01_python_warmup/lesson01_exercises.ipynb`；它與原本的 `lesson01_learning.ipynb` 內容相同，選一個檔案作答即可。Lesson 02 的練習和作業分別為 `lesson02_exercises.ipynb` 與 `lesson02_homework.ipynb`。

## 第一次使用

1. 在 GitHub 按 **Code → Download ZIP**，下載後先解壓縮。
2. 安裝 Python 3.10 以上、VS Code，以及 VS Code 的 Python 和 Jupyter 擴充功能。
3. 在 VS Code 選「開啟資料夾」，開啟解壓縮後包含 `lessons/` 和 `requirements.txt` 的資料夾。
4. 開啟命令面板（Windows：Ctrl+Shift+P；Mac：Cmd+Shift+P），選 **Python: Create Environment → Venv**，再選已安裝的 Python；若出現選項，勾選 `requirements.txt`。
5. 打開要使用的 `.ipynb`，右上角 **Select Kernel → Python Environments** 選課程的 `.venv`；若提示安裝 `ipykernel`，按安裝。
6. 由上到下執行，先執行工作資料夾設定格。練習題先完成 TODO；第 1 堂第 13 題是選做，需要網路。

請保存自己的練習副本；重新下載教材時，避免覆蓋已作答的 Notebook。
